# G-BRIDGE AI 발표자료 구성안

> 사업계획서 한 장으로 기업 진단부터 지원사업·기업 매칭·홍보 메일링까지 연결하는 기업지원 Intelligence 플랫폼

## 1. 한 줄 소개

**지원사업을 찾지 마세요. G-BRIDGE가 기업의 기회를 찾습니다.**

기업이 사업계획서를 업로드하면 기업의 성장단계와 핵심 병목을 진단하고, 진단 결과를 기반으로 맞춤형 지원사업과 협력기업, 후속 홍보까지 연결합니다.

---

## 2. 개발 이유

### 기존 기업지원의 문제

- 기업은 수많은 지원사업 중 어떤 사업이 적합한지 직접 찾아야 합니다.
- 지원사업 담당자는 사업계획서를 읽고 기업별 적합 사업을 수작업으로 분류합니다.
- 기업의 기술·시장·사업화 단계가 충분히 분석되지 않은 채 단순 공고 안내에 머무릅니다.
- 지원사업 추천, 기업 간 협력, 후속 홍보가 각각 분리되어 있습니다.

### 우리가 해결하려는 문제

사업계획서에 담긴 기업의 상황을 구조화하고, **진단 결과가 실제 지원과 매칭으로 이어지는 기업지원 흐름**을 만드는 것이 목표입니다.

### 기대 효과

| 대상 | 기대 효과 |
|---|---|
| 기업 | 나에게 맞는 지원사업과 성장기회를 빠르게 확인 |
| 지원 담당자 | 기업 선별·추천·홍보 업무 자동화 |
| 지원기관 | 누적된 기업 데이터를 기반으로 정책 수요 파악 |
| 협력기업 | 기술·수요 기반의 새로운 B2B 기회 발굴 |

## 3. 개발 컨셉

### 진단에서 끝나지 않는 기업지원

G-BRIDGE AI는 단순 문서 요약 서비스가 아닙니다.

```text
사업계획서 업로드
      ↓
기업 성장진단
      ↓
핵심 키워드·병목 추출
      ↓
맞춤 지원사업 추천
      ↓
기업·파트너 매칭
      ↓
키워드 기반 메일링·후속관리
```

### 핵심 컨셉 키워드

- **Evidence-based**: 사업계획서와 공공 자료에 근거한 진단
- **Keyword-driven**: `AI`, `제조`, `실증`, `POC`, `사업화`, `수출` 등 기업 키워드의 지속 활용
- **Actionable**: 분석 결과를 실행과제와 지원사업으로 연결
- **Connected**: 기업·지원사업·파트너·메일링을 하나의 흐름으로 연결
- **Public Impact**: 개별 기업 지원을 넘어 정책 데이터와 사업기획으로 확장

## 4. 서비스 핵심 기능

### 01 기업 성장진단

사업계획서를 분석해 기업의 기술·실행·시장 성숙도를 진단합니다.

- T·E·M 3축 성장단계 분석
- 핵심 병목과 우선 해결과제 도출
- 강점·약점·지원 요청사항 구조화
- 분석 키워드 자동 추출
- 분석 근거와 인용 카드 제공

### 02 맞춤 지원 연계

기업의 진단 결과와 키워드, 병목을 기준으로 관련 지원사업을 추천합니다.

- 추천 / 조건부 추천 / 비추천 분류
- 사업별 적합도와 추천 사유 제공
- 자격요건 검증
- 지원사업 원문 링크 제공
- 신청 사유서 자동 생성

### 03 기업 Discovery & 매칭

기업의 공급역량과 협력 니즈를 비교해 새로운 협력기회를 발굴합니다.

- 공급역량·기술·제품 기반 기업 프로필 생성
- 수요기업·파트너기업 탐색
- 공동 PoC·공급망·오픈이노베이션 매칭
- B2B 협력 제안서 초안 생성

### 04 키워드 기반 메일링

진단 키워드를 기준으로 기업군과 지원사업을 자동 연결합니다.

- 키워드별 대상 기업군 분류
- 키워드별 연계 지원사업 관리
- 알림톡·이메일 발송 채널 설정
- 추천 공고 자동 발송 현황 확인
- 기업별 발송 이력과 캠페인 관리

### 05 관리자 Intelligence

담당자가 기업 데이터와 분석 파이프라인을 한눈에 관리합니다.

- 기업 관리 및 진단 목록
- 성과·진단 현황 대시보드
- 맞춤형 알림톡·메일링 관리
- 공공 RAG 지식베이스 관리
- API 분석·RAG·기본 분석 fallback 관리

## 5. 사용 기술 — 핵심 강조

### AI·분석 기술

| 기술 | 활용 |
|---|---|
| **Google Gemini API** | 사업계획서 내용 분석, 기업 정보 구조화, 진단 결과 생성 |
| **Gemini File Search / RAG** | 문서 기반 검색과 분석 근거 보강 |
| **공공 RAG 지식베이스** | 지원사업·산업 리포트·정책 자료와 분석 결과 연결 |
| **T·E·M 진단 모델** | Technology·Execution·Market 성장단계 분석 |
| **Keyword Matching** | 기업 키워드와 지원사업·파트너·메일링 규칙 연결 |
| **Fallback 분석 규칙** | API 오류나 응답 지연에도 발표 흐름을 유지하는 기본 분석 |

### 프론트엔드 기술

- **React 18**: 컴포넌트 기반 화면 구성
- **TypeScript**: 기업·분석·지원사업 데이터의 타입 안정성 확보
- **Vite**: 빠른 개발 서버와 프로덕션 번들링
- **Tailwind CSS**: 일관된 디자인 시스템과 반응형 UI 구현
- **Recharts**: 관리자 대시보드 데이터 시각화
- **Framer Motion**: 분석 진행 상태와 인터랙션 표현
- **Lucide React / Material Symbols**: 기능 중심 아이콘 시스템

### 백엔드·데이터 연계

- **Vercel Serverless API**: `/api/gemini`를 통한 Gemini 호출
- **Supabase 연계 구조**: 기업·분석·지원사업·B2B 프로필 저장을 위한 스키마 설계
- **Type-safe Domain Model**: `Company`, `AnalysisResult`, `SupportProgram`, `CompanyB2BProfile`
- **GitHub + Vercel**: main 브랜치 기반 배포 파이프라인

> 발표 강조 포인트: **Gemini API를 단순 챗봇으로 사용한 것이 아니라, 사업계획서 → 구조화 데이터 → 진단 → 추천 → 매칭 → 메일링으로 이어지는 데이터 파이프라인으로 설계했습니다.**

## 7. 서비스 흐름

### 사용자 흐름

1. 기업 담당자가 PDF 사업계획서를 업로드합니다.
2. 문서에서 기업명·산업·기술·제품·시장·키워드를 추출합니다.
3. T·E·M 성장단계와 핵심 병목을 분석합니다.
4. 분석 키워드를 모든 후속 화면에 동일하게 표시합니다.
5. 맞춤 지원사업을 추천하고 적합도와 신청 사유를 제공합니다.
6. 공급역량과 협력 니즈를 기준으로 기업 매칭을 수행합니다.
7. 키워드가 일치하는 기업군에 지원사업 안내를 자동 메일링합니다.

### 담당자 흐름

1. 관리자 대시보드에서 접수·분석·매칭 현황을 확인합니다.
2. 기업별 상세 진단과 핵심 키워드를 확인합니다.
3. 추천 지원사업과 부적합 사업을 구분합니다.
4. 키워드별 메일링 규칙과 대상 기업을 확인합니다.
5. API 분석·RAG·기본 분석 fallback 상태를 관리합니다.
6. 누적 데이터를 기반으로 공통 병목과 신규 정책 수요를 발견합니다.

## 8. 데이터 흐름

```text
PDF 사업계획서
  ↓
Gemini API 분석
  ↓
Company / AnalysisResult / CompanyB2BProfile
  ↓
분석 키워드 생성
  ├─ 지원사업 매칭
  ├─ 기업 Discovery 매칭
  ├─ 메일링 대상 분류
  └─ 관리자 통계·정책 인사이트
```

### 핵심 데이터 모델

- `Company`: 기업 기본정보와 핵심 키워드
- `AnalysisResult`: T·E·M 진단, 병목, 강점, 약점, 실행계획
- `SupportProgram`: 지원사업, 예산, 자격요건, 대상 병목, 원문 링크
- `CompanyB2BProfile`: 기술·제품·공급역량·협력 니즈
- `B2BMatchResult`: 기업 간 적합도와 매칭 사유

## 9. 차별점

### 일반적인 AI 문서 분석과의 차이

| 일반적인 문서 AI | G-BRIDGE AI |
|---|---|
| 문서 요약 중심 | 기업 성장진단과 실행 연결 |
| 결과가 일회성 | 키워드가 매칭·메일링까지 지속 사용 |
| 지원사업 검색 중심 | 기업 병목과 자격요건 기반 추천 |
| 챗봇 응답 중심 | 관리자 운영 파이프라인 제공 |
| 기업 단위 분석 | 기업·지원사업·파트너·정책 데이터 연결 |

### 핵심 차별 문장

**G-BRIDGE는 기업의 사업계획서를 읽는 AI가 아니라, 기업의 다음 기회를 연결하는 운영 시스템입니다.**

## 10. 발표 데모 시나리오

### 3분 데모 구성

1. 메인 화면에서 서비스 컨셉 소개
2. 샘플 기업 또는 PDF 사업계획서 선택
3. 기업 성장진단 결과 확인
4. `AI`, `제조`, `실증`, `POC`, `사업화` 키워드 확인
5. 지원사업 추천 화면에서 추천·조건부·비추천 비교
6. 기업 Discovery 매칭 화면에서 협력 파트너 확인
7. 관리자 메일링 화면에서 키워드별 자동 발송 규칙 확인
8. 관리자 `분석 방법 관리`에서 API·RAG·fallback 파이프라인 확인

### 발표 중 강조할 장면

- 같은 기업 키워드가 진단 → 연계 → 매칭 → 메일링에 계속 이어지는 장면
- 지원사업을 단순 나열하지 않고 추천 사유와 자격요건을 함께 보여주는 장면
- API 분석과 기본 분석 fallback을 함께 준비해 서비스 중단 가능성을 낮춘 구조
- 담당자가 기업별 현황과 정책 데이터를 한 화면에서 확인하는 관리자 화면

## 11. 향후 발전 방향

- Supabase 기반 실데이터 저장·권한 관리

- 기업별 분석 이력과 성과 데이터 누적
- 이메일·알림톡 실제 발송 연계
- 분석 프롬프트와 추천 규칙 A/B 테스트
- 정책 담당자용 산업·지역·병목 분석 리포트
- 기업 성과 기반 추천 정확도 개선

## 12. 마무리 메시지

> **사업계획서 하나만 올리면, 기업의 가능성을 진단하고 필요한 지원을 연결하며 새로운 성장기회를 찾습니다.**

G-BRIDGE AI는 기업과 지원기관 사이의 정보 비대칭을 줄이고, 진단 데이터가 실제 지원·매칭·성과관리로 이어지는 기업지원 인프라를 지향합니다.
