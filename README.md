# G-BRIDGE AI

G-BRIDGE AI는 기업 사업계획서를 구조화해 T/E/M 진단, 지원사업 연계,
B2B 매칭 및 신규 사업 기획을 지원하기 위한 Vite + React 프로젝트입니다.

## 개발 환경

- Node.js 18 이상
- npm

## 시작하기

```bash
npm install
npm run dev
```

프로덕션 빌드는 다음 명령으로 확인합니다.

```bash
npm run build
```

## 환경 변수

API 키와 같은 비밀 정보는 `.env` 파일에만 저장하고 Git에 커밋하지 마세요.
필요한 환경 변수의 공개 가능한 예시는 `.env.example`에 작성합니다.

## 현재 상태

프로젝트 구조와 설정을 구성하는 초기 단계입니다. 상세한 제품 요구사항과 개발
규칙은 `docs/CODEX.md` 및 `.agents/rules/G_BRIDGE_RULES.md`를 참고하세요.
