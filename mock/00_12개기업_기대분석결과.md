### 01. 비전웍스AI — 제조 AI 비전검사

| 항목 | 내용 |
|---|---|
| 예상 단계 | T3 / E3 / M1 (M2에 근접하나 LOI·유상 없음) |
| 기업 인식 | 과검율 개선을 위한 차세대 AI 모델 추가개발이 필요 |
| 실제 병목 | **시장검증** — 기술·실증은 일정 수준인데 유상 고객 0 |
| 판단 근거 | 실제 생산라인 6주 2교대 PoC, 검출률 95.8% / PoC 2건 모두 무상, LOI·유상계약 없음 / 영업 전담 인력 없음(대표 직접 영업) / 가격 "개별 협의" / 2025년 매출 6,200만원은 용역 중심 |
| 핵심 강점 | 연구인력 9명, 실환경 연속 운영 경험, 12만 건 이미지, 특허 출원 2건 |
| 핵심 약점 | 유상 고객 0, 영업인력·가격정책 부재, 양산 레퍼런스 없음, 과도한 매출 목표 |
| 가장 중요한 성장 방향 | 시장진입 — A사 PoC의 유상 전환과 첫 레퍼런스 확보 |
| 보조 성장 방향 | 가격·영업체계 정비 |
| 현재 필요한 지원 | 실증 고도화(유상 전환형 실증), 초기 판로·수요기업 매칭 |
| 다음 단계 지원 | 판로 확대, 시장확대, 이후 투자 |
| 현재 우선순위 낮음 | 대규모 R&D, 3D 검사 연구, 해외 진출 |
| 확인 필요 | 매출 중 제품 판매 비중 / 정확도 비교기준(육안검사 대비) / PoC 수집 데이터의 활용 권리 / 투자 금액 / A사 도입 검토 단계 |
| 희망 vs 실제 | R&D 2.5억 요청 ↔ 과검율은 고객 요구지만 "도입 조건" 협상으로 풀 문제, 판매 시작이 우선 |
| **AI 인사이트** | 기술 수준은 이미 현장 적용 가능 단계. 병목은 기술이 아니라 유상 레퍼런스. 추가 R&D보다 실증 성과의 사업화 전환이 우선 |

| 가장 중요한 성장 방향 | 실증 확대 — 제조현장 장기 실증과 현장 데이터 축적 |

| 현재 필요한 지원 | 제조 테스트베드·현장 실증 지원, 수요기업 매칭(실증 목적) |
| 다음 단계 지원 | 초기 사업화·첫 유상 고객 |
| 현재 우선순위 낮음 | 대규모 판로, 베트남 진출 |
| 확인 필요 | 실험실 대비 현장 성능 / C사 데이터 권리·공유 / 데이터 보안 방침 / 해외 파트너 / 엔젤 투자 상태 |
| 희망 vs 실제 | 판로·해외 ↔ 현장 실증 |
| **AI 인사이트** | 알고리즘은 있으나 현장 검증이 전무해 판매할 근거가 없음. 판로보다 실증이 선행조건 |

| 항목 | 내용 |
|---|---|

| 보조 성장 방향 | 국내 시장확대(업종 다변화) |
| 현재 필요한 지원 | 해외시장 검증·글로벌 진출 지원, 현지 파트너 발굴 |
| 다음 단계 지원 | 수출 확대, 해외 레퍼런스 기반 투자 |
| 현재 우선순위 낮음 | 국내 PoC 추가 지원 |
| 확인 필요 | 고객 유지율 수치 / 해외 문의 후속 / 고객사 해외거점 수 / ARR |
| 희망 vs 실제 | 국내 PoC ↔ 해외 검증 |
| **AI 인사이트** | 국내에서는 이미 검증 단계를 지남. 고객사가 먼저 해외 적용을 묻는데 응답하지 않는 것이 가장 큰 기회 손실 |
